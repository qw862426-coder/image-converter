왜 PDF 하나로 내라고 할까요?

사진 여러 장을 따로 받으면 받는 사람이 하나씩 열어 봐야 하고, 순서가 섞이거나 빠지기 쉬워요. PDF 하나로 묶으면 한 파일 안에서 페이지를 넘기며 볼 수 있어서 회사 경비 처리, 학교 증빙, 지원 서류 제출에서 자주 요구해요.

합치는 법

  1. JPG를 PDF로 페이지를 열어요.
  2. 사진을 페이지 순서대로 골라요. 넣은 순서가 곧 PDF 페이지 순서예요.
  3. 여러 장을 PDF 파일 하나로 합치기가 켜져 있는지 확인해요. 끄면 사진마다 PDF가 따로 만들어져요.
  4. 변환하기를 누르고 PDF를 저장해요.

각 페이지는 사진 모양 그대로 들어가서 늘어나거나 잘리지 않아요. HEIC, PNG 사진도 섞어서 넣을 수 있어요.

용량 제한이 있을 때

휴대폰 사진 여섯 장을 그대로 합치면 PDF가 20~30MB가 되기도 해요. 제출 용량이 정해져 있다면 화질을 70% 정도로 낮춰서 다시 만들어 보세요. 대부분 글자를 읽는 데는 문제가 없으면서 용량이 크게 줄어요.

종이 서류를 찍은 사진이라면

영수증이나 서류를 책상 위에 놓고 찍으면 비스듬하고, 그림자가 지고, 책상 바닥이 같이 찍혀요. 이럴 때는 사진을 스캔본으로를 쓰세요. 종이 모서리를 찾아 반듯하게 펴고, 그림자를 지운 다음 PDF 하나로 만들어 줘요.

제출 전 확인할 것

  • PDF를 열어서 페이지 순서가 맞는지 보세요.
  • 영수증 금액, 날짜 같은 작은 글자가 읽히는지 확대해서 확인하세요.
  • 파일 이름을 "이름_서류이름.pdf"처럼 알아보기 쉽게 바꾸면 받는 사람이 편해요.

자주 묻는 질문

투명한 PNG를 넣으면요?

PDF에서는 투명한 부분이 흰색으로 바뀌어요.

사진이 업로드되나요?

아니요. PDF는 내 브라우저 안에서 만들어지고, 사진은 기기 밖으로 나가지 않아요. 신분증이나 통장 사본처럼 민감한 사진을 다룰 때 특히 중요해요.
