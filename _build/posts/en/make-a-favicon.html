What is a favicon?

A favicon is the small icon shown on browser tabs, in bookmarks and next to search results. Without one, browsers show a plain default icon and the site looks unfinished. It is usually a single file called favicon.ico.

One ICO file holds several sizes

An ICO file can contain several sizes of the same picture. A browser tab uses 16 pixels, a desktop shortcut uses a larger size, and each place picks the best fit. PicShifter puts 16, 32, 48, 64, 128 and 256 pixel versions in one file.

How to make one

  1. Prepare your logo. A square, transparent PNG of at least 256×256 pixels works best.
  2. Open PNG to ICO and choose the image. Non-square images are centred and padded so nothing is cut off.
  3. Press Convert and save the file as favicon.ico.

How to add it to your website

  1. Upload favicon.ico to the top folder of your site (where the home page file is). Most browsers look there automatically.
  2. To be sure, add this line inside the page’s <head>:

<link rel="icon" href="/favicon.ico">

Blog and shop platforms usually have a favicon upload box in their site settings instead.

Making it readable at tiny sizes

  • 16 pixels is tiny. A logo with words won’t read; use the first letter or just the symbol.
  • Bold shapes read better than thin lines.
  • Pick colours that show on both light and dark tabs.

The new icon doesn’t show

Browsers remember favicons for a long time. If you still see the old one, try another browser or a private window. Search results can take days or longer to update.
