Wann eine PDF teilen?

  • Nur die nötigen Seiten aus einem langen Bericht oder Vertrag verschicken.
  • Leere Seiten, Deckblätter oder Seiten mit persönlichen Daten vor dem Teilen entfernen.
  • Einen gescannten Stapel in eine Datei pro Dokument oder pro Seite trennen.

So teilst du eine PDF

  1. Wähle deine PDF; für jede Seite erscheint eine Vorschau.
  2. Tippe die gewünschten Seiten an oder gib Nummern wie 1-3, 5, 8- ein (8- heißt „ab Seite 8 bis zum Ende“).
  3. Wähle Behalten, Löschen oder Jede Seite als eigene PDF.
  4. Tippe auf PDF speichern.

Häufige Fragen

Bleibt der Text durchsuchbar?

Ja. Seiten werden unverändert kopiert, nicht in Bilder umgewandelt.

Was bekomme ich bei „Jede Seite als eigene PDF“?

Eine ZIP-Datei mit einer PDF pro Seite, der Reihe nach nummeriert.
