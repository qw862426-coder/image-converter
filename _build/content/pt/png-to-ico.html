Para que serve um arquivo ICO

ICO é o formato de ícones do Windows e do pequeno “favicon” que aparece nas abas e favoritos do navegador. Um arquivo ICO pode ter vários tamanhos, para que cada lugar use o mais nítido. Esta página cria versões de 16, 32, 48, 64, 128 e 256 pixels em um único arquivo.

Como fazer um favicon

  1. Escolha uma imagem quadrada, de preferência um PNG com fundo transparente e pelo menos 256×256 pixels.
  2. ICO já está selecionado. Imagens não quadradas são centralizadas e completadas com margens, então nada é cortado.
  3. Toque em Converter e salve o arquivo como favicon.ico.
  4. Envie-o para a pasta principal do seu site. A maioria dos navegadores procura /favicon.ico automaticamente.

Perguntas frequentes

Por que meu ícone fica borrado em 16 px?

Logotipos detalhados perdem nitidez nesse tamanho. Uma versão simplificada do logotipo, ou só a primeira letra, costuma funcionar melhor.

Posso criar um cursor de mouse?

Sim. Escolha CUR no menu de formato para criar um arquivo de cursor do Windows.

A transparência é mantida?

Sim. As áreas transparentes continuam transparentes em todos os tamanhos.
