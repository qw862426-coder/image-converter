PDF를 나누면 좋은 때

  • 긴 보고서나 계약서에서 필요한 페이지만 보낼 때
  • 공유하기 전에 빈 페이지, 표지, 개인정보가 있는 페이지를 뺄 때
  • 한꺼번에 스캔한 서류를 문서별·페이지별로 나눌 때

PDF 나누는 법

  1. PDF를 골라요. 모든 페이지가 작은 미리보기로 나와요.
  2. 원하는 페이지를 누르거나 1-3, 5, 8-처럼 번호를 입력해요. (8- 는 8쪽부터 끝까지라는 뜻이에요)
  3. 고른 페이지만 남기기, 고른 페이지 지우기, 한 페이지씩 따로 나누기 중에서 골라요.
  4. PDF 저장을 눌러요.

자주 묻는 질문

글자 검색이 계속 되나요?

네. 페이지를 그림으로 바꾸지 않고 그대로 복사해요.

"한 페이지씩 따로 나누기"는 어떻게 저장되나요?

페이지마다 PDF가 하나씩, 번호 순서대로 ZIP 파일 하나에 담겨요.

다른 파일의 페이지와 합칠 수 있나요?

네. PDF 합치기를 쓰세요.
