PDF를 합치면 좋은 때

  • 입사 지원할 때 이력서, 자기소개서, 자격증을 파일 하나로 보낼 때
  • 스캔한 영수증이나 세금계산서를 경비 처리용으로 모을 때
  • 여러 장의 자료를 인쇄하기 좋게 한 문서로 묶을 때

PDF 합치는 법

  1. PDF를 골라요. JPG, PNG 사진도 넣을 수 있고, 사진 한 장이 한 페이지가 돼요.
  2. 화살표로 순서를 정해요.
  3. PDF 하나로 합치기를 누르고 저장해요.

자주 묻는 질문

합치면 화질이 떨어지나요?

아니요. 페이지를 그대로 복사해서 글자, 그림, 링크가 원래대로 남아요.

비밀번호가 걸린 PDF도 되나요?

아직 안 돼요. 비밀번호로 연 다음 비밀번호 없이 다른 이름으로 저장해서 넣어 주세요.

파일 안의 페이지 순서도 바꿀 수 있나요?

PDF 나누기로 필요한 페이지를 뽑은 다음, 원하는 순서로 다시 합치면 돼요.
