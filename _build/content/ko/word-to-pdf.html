워드 파일을 PDF로 보내는 이유

워드 파일은 받는 사람의 컴퓨터에 다른 글꼴이나 다른 버전의 워드가 있으면 모양이 달라질 수 있고, 실수로 수정될 수도 있어요. PDF는 어디서 열어도 똑같이 보여서 입사 지원, 학교 과제, 회사 서류는 대부분 PDF를 요구해요.

워드를 PDF로 바꾸는 법

  1. 위에서 .docx 파일을 골라요. 여러 개를 한 번에 넣어도 돼요.
  2. PDF로 변환을 누르고 진행 막대가 끝날 때까지 기다려요.
  3. 저장을 눌러 PDF를 받아요.

자주 묻는 질문

모양이 그대로 유지되나요?

글자, 표, 그림, 페이지 나누기는 유지돼요. 복잡한 배치, 글상자, 내 기기에 없는 글꼴은 조금 달라 보일 수 있으니 보내기 전에 PDF를 확인하세요.

PDF에서 글자를 선택할 수 있나요?

아니요. 페이지가 그림으로 저장돼서 글자를 선택하거나 검색할 수 없어요.

예전 .doc 파일은요?

워드나 다른 편집 프로그램에서 열어 .docx로 저장한 뒤 사용하세요.

워드 그대로 보낼까, PDF로 보낼까?

함께 고쳐 쓰는 초안처럼 받는 사람이 글을 고쳐야 하면 .docx를 그대로 보내세요. 이력서, 자기소개서, 과제, 서명한 서류처럼 다 끝난 문서는 PDF가 좋아요. 내가 확인한 모양 그대로 보이고, 누가 실수로 글자를 바꿀 일도 없어요.

깔끔한 PDF를 만드는 팁

  • 맑은 고딕, 바탕, Arial처럼 흔한 글꼴을 쓰세요. 내 기기에 없는 글꼴은 비슷한 글꼴로 바뀌어 줄과 페이지가 밀릴 수 있어요.
  • 중요한 글은 일반 문단과 표에 넣으세요. 떠 있는 글상자와 도형이 가장 잘 어긋나요.
  • 새 페이지에서 시작해야 하는 곳은 엔터를 여러 번 치지 말고 페이지 나누기(Ctrl + Enter)를 넣으세요. 페이지 나누기는 PDF에서도 그대로 지켜져요.

예전 .doc 파일을 .docx로 바꾸는 법

  • 마이크로소프트 워드: 파일 → 다른 이름으로 저장 → "Word 문서(*.docx)"를 골라요.
  • 구글 문서: 파일을 연 뒤 파일 → 다운로드 → Microsoft Word(.docx)를 골라요.
  • 리브레오피스 Writer: 파일 → 다른 이름으로 저장 → Word 2007–365(.docx) 형식을 골라요.

더 묻는 질문

문서 안의 링크도 눌리나요?

아니요. 페이지가 그림으로 저장돼서 링크를 누를 수 없어요. 받는 사람이 링크를 써야 하면 주소를 전부 적어 두세요.

PDF가 워드 파일보다 큰 이유는요?

.docx는 글자를 저장하지만, 이 PDF는 페이지마다 그림을 저장해요. 그래서 긴 문서일수록 PDF가 커져요.
