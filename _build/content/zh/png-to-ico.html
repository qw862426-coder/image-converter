ICO 文件有什么用

ICO 是 Windows 图标以及浏览器标签页和书签上显示的小“网站图标”（favicon）所用的格式。一个 ICO 文件可以包含多种尺寸，每个位置都能选用最清晰的那个。本页会在一个文件中生成 16、32、48、64、128 和 256 像素的版本。

如何制作网站图标

  1. 选择一张正方形图片，最好是背景透明、至少 256×256 像素的 PNG。
  2. 已经选好了 ICO。非正方形的图片会居中并补齐边距，不会被裁掉。
  3. 点击转换，把文件保存为 favicon.ico。
  4. 把它上传到网站的根目录。大多数浏览器会自动查找 /favicon.ico。

常见问题

为什么图标在 16 px 时看起来模糊？

细节多的标志缩到这么小会变得不清楚。使用简化版标志或只用首字母，效果通常更好。

能制作鼠标指针吗？

能。在格式菜单中选择 CUR，即可制作 Windows 指针文件。

会保留透明吗？

会。每种尺寸中的透明区域都保持透明。
