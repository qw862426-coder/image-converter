What an ICO file is for

ICO is the icon format used by Windows and by the small “favicon” that appears on browser tabs and bookmarks. One ICO file can hold several sizes so each place can pick the sharpest one. This page creates 16, 32, 48, 64, 128 and 256 pixel versions in a single file.

How to make a favicon

  1. Choose a square image, ideally a PNG with a transparent background and at least 256×256 pixels.
  2. ICO is already selected. Non-square images are centred and padded so nothing is cut off.
  3. Press Convert and save the file as favicon.ico.
  4. Upload it to the main folder of your website. Most browsers look for /favicon.ico automatically.

Frequently asked questions

Why does my icon look blurry at 16 px?

Detailed logos lose clarity when they’re that small. A simplified version of the logo, or just its first letter, usually works better.

Can I make a mouse cursor?

Yes. Choose CUR in the format menu to make a Windows cursor file.

Is transparency kept?

Yes. Transparent areas stay transparent in every size.
