What is an HWP file?

HWP is the document format of Hangul (Hancom Office), the word processor widely used by Korean government offices, schools and companies. People outside Korea, and many Mac and phone users, can’t open HWP files without installing extra software. Converting to PDF lets anyone read and print them.

How to convert HWP to PDF

  1. Choose your .hwp files above.
  2. Press Convert to PDF.
  3. Save the PDF. Pages keep the paper size set in the document, usually A4.

Frequently asked questions

Are HWPX files supported?

Not yet. In Hangul, use “Save as” and choose the HWP format, then convert.

Will it look exactly like Hangul?

Text, tables and pictures are kept, but complex layouts and some fonts can look slightly different. Check the PDF before submitting it.

Do I need to install anything?

No. The HWP reader runs inside your browser.

Who needs HWP to PDF

  • Sending a Korean school or government form to someone abroad.
  • Opening an HWP attachment on a Mac, iPhone or Android phone without Hangul.
  • Submitting a document to a company that only accepts PDF.

If you only need to read a file now and then, Hancom also offers a free Hangul viewer app. To send a file that anyone can open, PDF is simpler.

Saving an HWPX file as HWP

Newer versions of Hangul can save in the HWPX format, which this tool can’t read yet. In Hangul, choose File → Save As, set the file type to “Hangul document (*.hwp)”, then convert the new file.

About fonts

Hangul documents often use fonts that come with Hancom Office, such as HCR Batang (Hamchorom Batang). Phones and most computers don’t have them, so a similar font is used instead and line breaks can move. For an exact match, convert on a computer where Hangul is installed.

More questions

Can I submit the PDF to a government office?

Many offices accept PDF, but some ask for the original HWP file. Check the submission rules first.

Will tables keep their borders?

Yes. Tables, borders and pictures are kept, though very complex tables may look slightly different.
