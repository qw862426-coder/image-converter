よく使う画像形式をひとつの場所で

スマホ、カメラ、ウェブサイト、デザインアプリは、それぞれ違う形式で画像を保存します。そのため、手元のファイルと必要なファイルの形式が違うことがよくあります。この変換ツールは、iPhoneのHEIC写真、PhotoshopのPSDファイル、PDFのページを含む17種類の画像形式を開けます。保存はJPG、PNG、WebP、PDFなど16種類の形式に対応しています。1枚だけでも、フォルダー1つ分をまとめてでも変換できます。

よく使われる変換

  • HEIC → JPG：iPhoneの写真をWindows、ウェブサイト、古い機器で開けるようにします。
  • PNG → JPG：大きなスクリーンショットや画像を軽くします。
  • JPG → PDF：複数の写真を1つの書類として送れます。
  • PDF → JPG：PDFの各ページを、投稿や貼り付けができる画像にします。
  • 画像を圧縮：縦横のピクセル数はそのままで、アップロードの容量制限に収めます。
  • PNG → ICO：ウェブサイト用のファビコンを作ります。

画質の設定とは？

JPG、WebP、PDFは「非可逆」形式で、目立たない細部を省いて容量を減らします。画質スライダーは、どれだけ省くかを決めます。90%以上なら、ほとんどの人は元の画像と区別できません。70〜80%くらいならファイルがかなり小さくなり、スマホの画面では十分きれいに見えます。50%を下回ると、ブロック状のノイズが見え始めることがあります。PNG、GIF、BMP、TIFFはすべてのピクセルを保つため、スライダーは表示されません。

よくある質問

ファイルサイズや枚数に制限はありますか？

サイト側の制限はありません。ただし変換はお使いの端末自身が行うため、とても大きな画像や数百枚を一度に変換すると、古いスマホでは遅くなることがあります。その場合は何回かに分けて変換してください。

AVIFが選べないのはなぜですか？

AVIFで保存できるかはブラウザによります。AVIFを開くことはほとんどのブラウザでできますが、作成できるのは一部のブラウザだけです。選択肢がグレーになっている場合は、最新のChromeでお試しください。

画像のコピーは保存されますか？

いいえ。画像はブラウザの中で読み込まれて変換され、サーバーに送られることはありません。そのため運営者が保存するものもありません。
