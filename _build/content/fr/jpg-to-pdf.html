Un seul PDF pour plusieurs photos

Les formulaires et les e-mails demandent souvent « un PDF » plutôt qu’une pile de photos. Cette page place toutes les images choisies dans un seul PDF, une image par page, dans l’ordre où vous les avez ajoutées. Chaque page prend la taille de sa photo : rien n’est étiré ni rogné.

Comment créer un PDF à partir d’images

  1. Choisissez vos photos ci-dessus, dans l’ordre voulu pour les pages.
  2. PDF est sélectionné et Tout réunir dans un seul fichier PDF est activé. Désactivez-le pour obtenir un PDF par photo.
  3. Baissez la qualité à environ 70 % si le PDF doit rester sous une taille maximale.
  4. Appuyez sur Convertir et enregistrez le PDF.

Questions fréquentes

Puis-je aussi utiliser des photos HEIC ou PNG ?

Oui. Toute image que le convertisseur sait ouvrir peut aller dans le PDF.

Mes photos montrent des documents papier. Peuvent-elles ressembler à un scan ?

Utilisez Photo en scan. L’outil redresse la page et supprime les ombres avant de créer le PDF.

Les zones transparentes sont-elles conservées ?

Non. Les parties transparentes deviennent blanches dans le PDF.
