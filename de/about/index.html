Über PicShifter

PicShifter ist eine kleine Sammlung kostenloser Tools zum Ändern von Dateiformaten: Bilder zwischen JPG, PNG, WebP, HEIC und mehr, Word-, Excel-, PowerPoint- und Hangul-Dokumente zu PDF, Handyfotos von Papier zu sauberen Scans und Fotos zu Freistellern ohne Hintergrund.

Warum es diese Seite gibt

Die meisten Online-Konverter verlangen, dass du deine Dateien auf ihre Server hochlädst. Das ist mit mobilen Daten langsam und bei privaten Fotos oder Arbeitsdokumenten unangenehm. PicShifter wandelt stattdessen direkt in deinem Browser um, deine Dateien verlassen also nie dein Gerät.

So funktioniert es

Wenn du ein Tool öffnest, lädt dein Browser den Umwandlungscode von dieser Seite. Dieser Code liest und wandelt deine Dateien auf deinem Handy oder Computer um, und das Ergebnis wird direkt auf deinem Gerät gespeichert.

Verwendete Open-Source-Software

PicShifter baut auf diesen Open-Source-Projekten auf, die gemäß ihren Lizenzen genutzt werden: pdf.js (Apache-2.0), heic2any (MIT), html2canvas (MIT), docx-preview (Apache-2.0), JSZip (MIT), SheetJS Community Edition (Apache-2.0), PPTXjs (MIT), jQuery (MIT), D3 (BSD-3-Clause), NVD3 (Apache-2.0), hwp.js (Apache-2.0), cfb (Apache-2.0), pako (MIT) und ONNX Runtime (MIT). Für das Entfernen des Hintergrunds werden das U2-Net-Modell von Xuebin Qin et al. (Apache-2.0) und das mit rembg von Daniel Gatis verteilte Modell „silueta“ (MIT) verwendet. Danke an die Autorinnen und Autoren. Der Quellcode dieser Seite ist auf GitHub verfügbar.
