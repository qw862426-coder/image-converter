Report a problem or make a suggestion

Open an issue on our GitHub issues page. Please include the file type, your device and browser, and what happened. Don’t attach private files.

Before you write

  • Check the guide, which covers the most common problems.
  • If downloads don’t start, open the site in Safari or Chrome instead of an in-app browser.
