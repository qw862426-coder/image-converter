How to use PicShifter

A practical guide to the two free tools on this site: the image converter and the documents-to-PDF converter. Both run inside your browser, so your files stay on your device.

1. Converting images

  1. Open the image converter.
  2. Tap the dashed box and pick one or more images, or drag them onto it on a computer.
  3. Choose the format you want under Convert to. For JPG, WebP and PDF you can also set the quality.
  4. Press Convert. Each file shows its old and new size.
  5. Press Save next to a file, or Save all to download everything.

You can mix file types in one batch. For example, you can turn a HEIC photo, a PNG screenshot and a PSD file into JPG at the same time.

Choosing PDF lets you combine all selected images into one PDF, which is handy for sending scanned receipts or a set of photos as a single file.

2. Which image format should I choose?

A simple rule: photos go to JPG, anything with text or a transparent background goes to PNG, and images for your own website go to WebP.

Making files smaller

Lowering the quality slider to 70–80% usually cuts a JPG or WebP file size a lot while the picture still looks the same on a phone screen. PNG does not use the slider because it never throws away detail.

3. iPhone photos (HEIC) to JPG

iPhones save photos as HEIC by default. HEIC files are small, but many Windows programs, websites and older devices can’t open them.

  1. Pick your HEIC photos in the image converter.
  2. Choose JPG and press Convert.
  3. Save the JPG files. They open on any device.

If you want your iPhone to take JPG photos from now on, go to Settings → Camera → Formats and choose Most Compatible.

4. Converting documents to PDF

  1. Open Documents to PDF.
  2. Pick Word (DOCX), Excel (XLSX, XLS, CSV), PowerPoint (PPTX) or Hangul (HWP) files.
  3. Press Convert to PDF and wait for the progress bar.
  4. Press Save to download each PDF.

What happens to each file type

  • Word: each page becomes a PDF page. Long sections without page breaks are split to the page size.
  • Excel: every sheet is printed as a table with its name on top. Wide sheets switch to landscape pages.
  • PowerPoint: each slide becomes one landscape page.
  • Hangul (HWP): pages keep the paper size set in the document, usually A4.

Limits to know: the PDF is made of page images, so text can’t be selected or searched. Layout may differ slightly from the original, and fonts you don’t have are replaced. Old DOC and PPT files and HWPX files need to be saved as DOCX, PPTX or HWP first.

5. When something goes wrong

  • “This file can’t be opened as an image”: the file may be damaged, or its name ends in the wrong extension. Try opening it in another app first.
  • The Save button does nothing: some in-app browsers (inside messengers or social apps) block downloads. Open the site in Safari or Chrome.
  • A document stops with an error: password-protected files can’t be read. Remove the password and try again.
  • Conversion is slow: very large documents and photos take longer on phones. Convert fewer files at once.

6. Frequently asked questions

Are my files uploaded anywhere?

No. The page loads the conversion tools into your browser and converts files there. Nothing is sent to a server, which is also why it keeps working for files you’d rather not share.

Is it free?

Yes. There’s no sign-up and no file limit. The site may show ads to cover its costs.

Does it work on phones?

Yes, on recent versions of Safari, Chrome, Edge and Samsung Internet.

1. 이미지 변환하기

  1. 이미지 변환기를 열어요.
  2. 점선 상자를 눌러 사진을 한 장 이상 고르거나, 컴퓨터라면 상자 위로 끌어다 놓아요.
  3. 바꿀 형식에서 원하는 형식을 골라요. JPG, WebP, PDF는 화질도 정할 수 있어요.
  4. 변환하기를 누르면 파일마다 원래 용량과 바뀐 용량이 보여요.
  5. 파일 옆 저장을 누르거나, 전체 저장으로 한 번에 받아요.

형식이 다른 파일을 섞어서 올려도 돼요. 예를 들어 HEIC 사진, PNG 캡처, PSD 파일을 한 번에 JPG로 바꿀 수 있어요.

PDF를 고르면 고른 사진들을 PDF 파일 하나로 합칠 수 있어요. 영수증 사진이나 여러 장의 사진을 한 파일로 보낼 때 편해요.

용량 줄이기

화질을 70~80%로 낮추면 JPG나 WebP 용량이 크게 줄어도 휴대폰 화면에서는 거의 차이가 안 나요. PNG는 화질을 버리지 않는 형식이라 화질 조절이 없어요.

3. 아이폰 사진(HEIC)을 JPG로

아이폰은 기본으로 사진을 HEIC로 저장해요. 용량은 작지만 윈도우 프로그램, 일부 홈페이지, 오래된 기기에서는 안 열려요.

  1. 이미지 변환기에서 HEIC 사진을 골라요.
  2. JPG를 고르고 변환하기를 눌러요.
  3. JPG 파일을 저장하면 어느 기기에서나 열려요.

앞으로 아이폰이 처음부터 JPG로 찍게 하려면 설정 → 카메라 → 포맷에서 높은 호환성을 고르면 돼요.

4. 문서를 PDF로 바꾸기

  1. 문서를 PDF로 페이지를 열어요.
  2. 워드(DOCX), 엑셀(XLSX, XLS, CSV), 파워포인트(PPTX), 한글(HWP) 파일을 골라요.
  3. PDF로 변환을 누르고 진행 막대가 끝날 때까지 기다려요.
  4. 저장을 눌러 PDF를 받아요.

파일 종류별로 이렇게 바뀌어요

  • 워드: 페이지마다 PDF 한 쪽이 돼요. 페이지 나누기 없이 긴 부분은 종이 크기에 맞춰 나눠요.
  • 엑셀: 시트마다 이름을 위에 적고 표로 담아요. 가로로 넓은 시트는 가로 방향 페이지가 돼요.
  • 파워포인트: 슬라이드 하나가 가로 페이지 하나가 돼요.
  • 한글(HWP): 문서에 정해진 용지 크기(보통 A4)를 그대로 써요.

알아둘 점: PDF는 페이지를 그림으로 만들어 담기 때문에 글자를 선택하거나 검색할 수 없어요. 원본과 모양이 조금 다를 수 있고, 내 기기에 없는 글꼴은 다른 글꼴로 바뀌어요. 옛날 DOC, PPT 파일과 HWPX 파일은 먼저 DOCX, PPTX, HWP로 저장해 주세요.

5. 잘 안 될 때

  • "이 파일을 그림으로 열 수 없어요"가 뜰 때: 파일이 손상됐거나 확장자가 잘못 붙어 있을 수 있어요. 다른 앱에서 먼저 열어보세요.
  • 저장 버튼을 눌러도 아무 일이 없을 때: 카카오톡 같은 앱 안의 브라우저는 다운로드를 막는 경우가 있어요. 사파리나 크롬으로 열어주세요.
  • 문서 변환 중 오류가 날 때: 암호가 걸린 파일은 읽을 수 없어요. 암호를 푼 뒤 다시 시도해 주세요.
  • 변환이 느릴 때: 아주 큰 문서나 사진은 휴대폰에서 시간이 더 걸려요. 한 번에 올리는 파일 수를 줄여보세요.

6. 자주 묻는 질문

파일이 어딘가에 업로드되나요?

아니요. 페이지가 변환 도구를 브라우저로 불러와서 그 안에서 바로 변환해요. 서버로 보내는 게 없어서, 남에게 보이기 싫은 파일도 안심하고 쓸 수 있어요.

무료인가요?

네. 가입도 필요 없고 파일 개수 제한도 없어요. 운영비를 위해 광고가 보일 수 있어요.

휴대폰에서도 되나요?

네. 최신 사파리, 크롬, 엣지, 삼성 인터넷에서 쓸 수 있어요.
