PicShifterの使い方

このサイトの無料ツール（画像変換、文書をPDFに、写真をスキャンに、背景削除）の実用ガイドです。どのツールもブラウザの中で動くので、ファイルはお使いの端末から外に出ません。

1. 画像を変換する

  1. 画像変換を開きます。
  2. 点線の枠をタップして画像を1枚以上選びます。パソコンでは枠にドラッグしてもかまいません。
  3. 変換先で形式を選びます。JPG・WebP・PDFでは画質も設定できます。
  4. 変換するを押します。各ファイルに変換前と変換後のサイズが表示されます。
  5. ファイルごとの保存、またはまとめてダウンロードするすべて保存を押します。

種類の違うファイルを一度に変換できます。たとえばHEICの写真、PNGのスクリーンショット、PSDファイルを同時にJPGにできます。

PDFを選ぶと、選んだ画像をすべて1つのPDFにまとめられます。レシートのスキャンや複数の写真を1ファイルで送りたいときに便利です。

2. どの画像形式を選べばいい？

形式向いている用途透明部分
JPG共有やアップロードする写真。ファイルが小さく、どこでも開けます。保持しない（白になる）
PNGスクリーンショット、ロゴ、文字や輪郭がくっきりした画像。画質は劣化しません。保持する
WebPウェブサイト用の画像。同じ画質ならたいていJPGより小さくなります。保持する
PDF複数の画像を1つの書類として送る、印刷する。保持しない
GIFシンプルな図。256色までなので写真は粗く見えます。保持する（透明か不透明のみ）
ICOウェブサイトのアイコン（ファビコン）やWindowsのアイコン。保持する
TIFF、PSD、TGA、DDS印刷所、Photoshop、ゲーム制作ツールに渡すとき。保持する

簡単な目安：写真はJPG、文字や透明な背景があるものはPNG、自分のウェブサイトに載せる画像はWebP。

ファイルを小さくするには

画質スライダーを70〜80%に下げると、スマホの画面では見た目がほとんど変わらないまま、JPGやWebPのファイルサイズを大きく減らせます。PNGは細部を一切捨てない形式なので、スライダーは使いません。

3. iPhoneの写真（HEIC）をJPGに

iPhoneは初期設定で写真をHEIC形式で保存します。HEICはファイルが小さい反面、多くのWindowsソフト、ウェブサイト、古い機器では開けません。

  1. 画像変換でHEICの写真を選びます。
  2. JPGを選んで変換するを押します。
  3. JPGファイルを保存します。どの端末でも開けます。

今後iPhoneでJPGの写真を撮りたい場合は、設定 → カメラ → フォーマットで互換性優先を選んでください。

4. 文書をPDFに変換する

  1. 文書をPDFにを開きます。
  2. Word（DOCX）、Excel（XLSX・XLS・CSV）、PowerPoint（PPTX）、ハングル（HWP）のファイルを選びます。
  3. PDFに変換を押し、進行バーが終わるまで待ちます。
  4. 保存を押して各PDFをダウンロードします。

ファイルの種類ごとの変換結果

  • Word：各ページがPDFの1ページになります。改ページのない長い部分は用紙サイズで分割されます。
  • Excel：シートごとに、上部にシート名を付けた表として出力します。横に長いシートは横向きのページになります。
  • PowerPoint：1枚のスライドが横向きの1ページになります。
  • ハングル（HWP）：文書で設定された用紙サイズ（多くはA4）のままになります。

知っておきたい制限：PDFはページの画像で作られるため、文字の選択や検索はできません。レイアウトが元とわずかに異なる場合があり、端末にないフォントは置き換えられます。古いDOC・PPTファイルやHWPXファイルは、先にDOCX・PPTX・HWPとして保存し直してください。

5. 紙の写真をスキャンにする

署名した書類やレシート、手書きのメモを送りたいのにスキャナーがない？ スマホで写真を撮って、写真をスキャンにできれいに整えましょう。

  1. 紙を暗めの無地の面に平らに置き、真上から撮影します。
  2. 写真をスキャンにを開いて写真を追加します。写真1枚が1ページになります。
  3. ツールが紙の端を見つけてまっすぐに補正します。枠がずれている場合は角を調整をタップし、4つの点を紙の角までドラッグします。
  4. 仕上がりを選びます。文字には白黒、鉛筆のメモにはグレースケール、レシート・印鑑・写真にはカラー、補正だけしたいときは元の色。
  5. 回転と矢印でページの向きと順番を直します。
  6. 全ページを1つのファイルにするならPDF（A4、レター、写真に合わせる）、1枚ずつの画像ならJPG/PNGを選び、保存を押します。

きれいになる仕組み

ツールは、文字の下にある紙の明るさをページ全体で推定し、それを均一にします。これにより手やスマホの灰色の影が消え、黄ばんだ紙が白くなり、インクは濃いまま残ります。

きれいに仕上げるコツ

  • ページ全体を均一に照らします。天井の照明1つより、昼間の窓辺のほうがきれいに撮れます。
  • 写真の大部分を紙で埋めつつ、4つの角はすべて写るようにします。
  • スマホをしっかり固定します。ブレは後から直せません。

6. 写真の背景を削除する

背景を削除は、人物・ペット・商品など写真の主役を切り抜き、背景が透明なPNGにします。プロフィール写真、ネットショップの商品画像、ステッカー、スライドに便利です。

  1. 背景を削除を開き、写真を1枚以上追加します。
  2. 輪郭をきれいにしたいなら高品質、通信が遅いときは高速を選びます。高品質は初回だけ44 MBのAIモデルをダウンロードし、次回からはブラウザに保存されたものを使います。
  3. 各写真の処理が終わるまで待ちます。元画像をタップすると処理前と比べられます。
  4. 背景を選びます。透明はPNGで保存し、白や色はその背景で塗りつぶしたJPGで保存します。
  5. 保存、または複数あるときはすべて保存を押します。

うまくいきやすい写真

  • シンプルな背景の前に、はっきりした主役が1つだけ写っている。
  • 明るく、主役にピントが合っている。
  • 主役が写真の端で必要以上に切れていない。

人混みの街並み、細くはねた髪の毛、ガラスなど透ける物は、どんな自動ツールでも苦手です。きれいに切り抜けないときは、背景がもっとシンプルな写真で試してください。

7. うまくいかないとき

  • 「画像として開けないファイルです」と出る：ファイルが壊れているか、拡張子が間違っている可能性があります。まず別のアプリで開けるか試してください。
  • 保存ボタンを押しても何も起きない：メッセンジャーやSNSアプリ内のブラウザでは、ダウンロードがブロックされることがあります。SafariかChromeでサイトを開いてください。
  • 文書の変換がエラーで止まる：パスワード付きのファイルは読み込めません。パスワードを外してからもう一度試してください。
  • 変換が遅い：大きな文書や写真は、スマホでは時間がかかります。一度に変換するファイルを減らしてください。

8. よくある質問

ファイルはどこかにアップロードされますか？

いいえ。ページが変換ツールをブラウザに読み込み、そこで変換します。サーバーには何も送られないので、人に見せたくないファイルでも安心して使えます。

無料ですか？

はい。登録不要で、ファイル数の制限もありません。運営費のために広告が表示されることがあります。

スマホでも使えますか？

はい。最近のSafari、Chrome、Edge、Samsung Internetで使えます。
