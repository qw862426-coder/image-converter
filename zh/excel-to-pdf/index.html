Excel 转 PDF

把 Excel 工作表转换成便于打印和分享的 PDF。所有操作都在你的设备上完成。

点击这里选择文档，或把文档拖到这里 Word（DOCX）· Excel（XLSX、XLS、CSV）· PowerPoint（PPTX）· Hangul（HWP）· 可一次选择多个

    还没有选择文档。

    注意事项

    • PDF 由页面图片组成，因此其中的文字无法选择或搜索。
    • 排版可能与原文件略有不同，复杂的 PowerPoint 和 Hangul 文档尤其如此。设备上没有的字体会被替换。
    • 不支持旧格式（DOC、PPT）和 HWPX。请先另存为 DOCX、PPTX 或 HWP。

    用 PDF 分享表格

    把价格表、日程表或报告发给只需要阅读或打印的人，PDF 是最简单的方式。对方不需要 Excel，也不会不小心改动你的数字。

    如何把 Excel 转成 PDF

    1. 在上方选择你的 .xlsx、.xls 或 .csv 文件。
    2. 点击转换为 PDF。
    3. 保存 PDF。每个工作表从新的一页开始，顶部显示表名。

    转换效果

    • 单元格的值按 Excel 中的显示方式输出，包括数字格式。
    • 很长的工作表会延续到多页 A4；很宽的工作表会改用横向。
    • 不包含 Excel 中的图表、图片、颜色和打印设置。如需这些，请使用 Excel 自带的“另存为 PDF”。

    常见问题

    公式会保留吗？

    PDF 显示的是计算结果，而不是公式。

    能转换 CSV 文件吗？

    能。CSV 文件会作为一个工作表读取。
