1. 转换图片

  1. 打开图片转换。
  2. 点击虚线框，选择一张或多张图片；在电脑上也可以直接拖进框里。
  3. 在转换为中选择目标格式。JPG、WebP 和 PDF 还可以设置画质。
  4. 点击转换。每个文件都会显示转换前后的大小。
  5. 点击文件旁边的保存，或点击全部保存一次下载所有文件。

一次可以混合转换不同类型的文件。例如，可以同时把 HEIC 照片、PNG 截图和 PSD 文件转成 JPG。

选择 PDF 时，可以把所有选中的图片合并成一个 PDF，方便把扫描的收据或一组照片作为一个文件发送。

2. 该选哪种图片格式？

格式适合用途保留透明
JPG要分享或上传的照片。文件小，到处都能打开。否（变成白色）
PNG截图、标志、带文字或边缘清晰的图片。画质无损。是
WebP网站用图片。同等画质下通常比 JPG 更小。是
PDF把多张图片作为一份文档发送、打印。否
GIF简单的图形。最多 256 色，照片会显得粗糙。是（只有透明/不透明）
ICO网站图标（favicon）和 Windows 图标。是
TIFF、PSD、TGA、DDS交给印刷店、Photoshop 或游戏制作工具。是

简单规则：照片用 JPG，带文字或透明背景的用 PNG，放在自己网站上的图片用 WebP。

让文件变小

把画质滑块调到 70–80%，通常能大幅减小 JPG 或 WebP 文件，而在手机屏幕上看起来几乎没有变化。PNG 从不丢弃细节，所以不使用滑块。

3. iPhone 照片（HEIC）转 JPG

iPhone 默认用 HEIC 格式保存照片。HEIC 文件小，但很多 Windows 软件、网站和旧设备打不开。

  1. 在图片转换中选择你的 HEIC 照片。
  2. 选择 JPG，然后点击转换。
  3. 保存 JPG 文件，任何设备都能打开。

如果想让 iPhone 以后直接拍 JPG 照片，请前往设置 → 相机 → 格式，选择兼容性最佳。

4. 把文档转换成 PDF

  1. 打开文档转 PDF。
  2. 选择 Word（DOCX）、Excel（XLSX、XLS、CSV）、PowerPoint（PPTX）或韩文（HWP）文件。
  3. 点击转换为 PDF，等待进度条完成。
  4. 点击保存下载每个 PDF。

各类文件的转换结果

  • Word：每一页变成 PDF 的一页。没有分页符的长段落会按页面大小拆分。
  • Excel：每个工作表都以表格形式输出，顶部带有表名。很宽的工作表会改用横向页面。
  • PowerPoint：每张幻灯片变成一页横向页面。
  • 韩文（HWP）：页面保持文档中设置的纸张大小，通常是 A4。

需要了解的限制：PDF 由页面图片组成，因此文字无法选中或搜索。版式可能与原文件略有不同，设备上没有的字体会被替换。旧的 DOC、PPT 文件和 HWPX 文件需要先另存为 DOCX、PPTX 或 HWP。

5. 把纸张照片变成扫描件

要发送签好字的表格、收据或手写笔记，却没有扫描仪？用手机拍张照，交给照片转扫描件来整理吧。

  1. 把纸平放在颜色较深的纯色桌面上，从正上方拍照。
  2. 打开照片转扫描件并添加照片。每张照片成为一页。
  3. 工具会自动找到纸张边缘并把它拉正。如果框选不准，点击调整四角，把四个圆点拖到纸张的四个角上。
  4. 选择效果：文字用黑白，铅笔笔记用灰度，收据、印章和照片用彩色，只想拉正就选原图。
  5. 用旋转和箭头调整页面方向和顺序。
  6. 想把所有页面合成一个文件就选 PDF（A4、Letter 或按照片大小），想要单独的图片就选 JPG/PNG，然后点击保存。

清理效果的原理

工具会估算整页文字下面纸张的亮度，再把它调匀。这样可以去掉手或手机留下的灰色阴影，让发黄的纸变白，同时保持墨迹清晰深色。

获得最佳效果

  • 让整页光线均匀。白天靠窗拍摄比只开一盏顶灯效果更好。
  • 让纸张占满照片的大部分，但四个角都要拍进去。
  • 拿稳手机。模糊无法事后修复。

6. 去除照片背景

去除背景可以把照片中的主体（人物、宠物或商品）抠出来，生成背景透明的 PNG。适合头像、网店商品图、贴纸和幻灯片。

  1. 打开去除背景，添加一张或多张照片。
  2. 想要更干净的边缘就选高质量，网络慢时选快速。高质量首次使用时会下载一个 44 MB 的 AI 模型，之后浏览器会保存下来。
  3. 等待每张照片处理完成。点击原图可以对比前后效果。
  4. 选择背景：透明保存为 PNG，白色或颜色会保存为填充了该背景的 JPG。
  5. 点击保存，多张照片可点击全部保存。

效果最好的照片

  • 只有一个清晰的主体，并且在简单的背景前很突出。
  • 光线充足，主体对焦清晰。
  • 主体没有被照片边缘过多地截掉。

拥挤的街景、细碎飘散的头发，以及玻璃等透明物体，对任何自动工具来说都很难。如果效果不干净，换一张背景更简单的照片试试。

7. 遇到问题时

  • “此文件无法作为图片打开”：文件可能已损坏，或扩展名不对。先试着用别的应用打开它。
  • 点击保存按钮没反应：一些应用内浏览器（聊天或社交应用中的）会阻止下载。请在 Safari 或 Chrome 中打开本站。
  • 文档转换报错停止：无法读取有密码保护的文件。去掉密码后再试一次。
  • 转换很慢：在手机上处理很大的文档和照片需要更长时间。一次少转换几个文件。

8. 常见问题

我的文件会被上传到哪里吗？

不会。页面把转换工具加载到你的浏览器中，在那里完成转换。不会向服务器发送任何内容，所以不想给别人看的文件也可以放心使用。

免费吗？

免费。无需注册，也没有文件数量限制。网站可能会显示广告来支付运营成本。

手机上能用吗？

能，支持较新版本的 Safari、Chrome、Edge 和三星浏览器。
