1. 이미지 변환하기

  1. 이미지 변환기를 열어요.
  2. 점선 상자를 눌러 사진을 한 장 이상 고르거나, 컴퓨터라면 상자 위로 끌어다 놓아요.
  3. 바꿀 형식에서 원하는 형식을 골라요. JPG, WebP, PDF는 화질도 정할 수 있어요.
  4. 변환하기를 누르면 파일마다 원래 용량과 바뀐 용량이 보여요.
  5. 파일 옆 저장을 누르거나, 전체 저장으로 한 번에 받아요.

형식이 다른 파일을 섞어서 올려도 돼요. 예를 들어 HEIC 사진, PNG 캡처, PSD 파일을 한 번에 JPG로 바꿀 수 있어요.

PDF를 고르면 고른 사진들을 PDF 파일 하나로 합칠 수 있어요. 영수증 사진이나 여러 장의 사진을 한 파일로 보낼 때 편해요.

2. 어떤 이미지 형식을 골라야 할까?

형식이럴 때 좋아요투명 배경 유지
JPG사진을 보내거나 올릴 때. 용량이 작고 어디서나 열려요.안 됨 (흰색으로 바뀜)
PNG화면 캡처, 로고, 글자가 있는 그림. 화질이 떨어지지 않아요.됨
WebP홈페이지용 이미지. 같은 화질이면 보통 JPG보다 작아요.됨
PDF여러 장을 문서 하나로 보내거나 인쇄할 때.안 됨
GIF단순한 그림. 최대 256색이라 사진은 거칠게 보여요.됨 (투명/불투명만)
ICO홈페이지 아이콘(파비콘), 윈도우 아이콘.됨
TIFF, PSD, TGA, DDS인쇄소, 포토샵, 게임 제작 도구에 넘길 때.됨

쉽게 정리하면, 사진은 JPG, 글자나 투명 배경이 있으면 PNG, 내 홈페이지에 올릴 이미지는 WebP가 좋아요.

용량 줄이기

화질을 70~80%로 낮추면 JPG나 WebP 용량이 크게 줄어도 휴대폰 화면에서는 거의 차이가 안 나요. PNG는 화질을 버리지 않는 형식이라 화질 조절이 없어요.

3. 아이폰 사진(HEIC)을 JPG로

아이폰은 기본으로 사진을 HEIC로 저장해요. 용량은 작지만 윈도우 프로그램, 일부 홈페이지, 오래된 기기에서는 안 열려요.

  1. 이미지 변환기에서 HEIC 사진을 골라요.
  2. JPG를 고르고 변환하기를 눌러요.
  3. JPG 파일을 저장하면 어느 기기에서나 열려요.

앞으로 아이폰이 처음부터 JPG로 찍게 하려면 설정 → 카메라 → 포맷에서 높은 호환성을 고르면 돼요.

4. 문서를 PDF로 바꾸기

  1. 문서를 PDF로 페이지를 열어요.
  2. 워드(DOCX), 엑셀(XLSX, XLS, CSV), 파워포인트(PPTX), 한글(HWP) 파일을 골라요.
  3. PDF로 변환을 누르고 진행 막대가 끝날 때까지 기다려요.
  4. 저장을 눌러 PDF를 받아요.

파일 종류별로 이렇게 바뀌어요

  • 워드: 페이지마다 PDF 한 쪽이 돼요. 페이지 나누기 없이 긴 부분은 종이 크기에 맞춰 나눠요.
  • 엑셀: 시트마다 이름을 위에 적고 표로 담아요. 가로로 넓은 시트는 가로 방향 페이지가 돼요.
  • 파워포인트: 슬라이드 하나가 가로 페이지 하나가 돼요.
  • 한글(HWP): 문서에 정해진 용지 크기(보통 A4)를 그대로 써요.

알아둘 점: PDF는 페이지를 그림으로 만들어 담기 때문에 글자를 선택하거나 검색할 수 없어요. 원본과 모양이 조금 다를 수 있고, 내 기기에 없는 글꼴은 다른 글꼴로 바뀌어요. 옛날 DOC, PPT 파일과 HWPX 파일은 먼저 DOCX, PPTX, HWP로 저장해 주세요.

5. 종이 사진을 스캔본으로 만들기

서명한 서류, 영수증, 손글씨 필기를 보내야 하는데 스캐너가 없나요? 휴대폰으로 찍고 사진 → 스캔본에서 깔끔하게 만들면 돼요.

  1. 종이를 무늬 없는 어두운 바닥에 평평하게 놓고 위에서 찍어요.
  2. 사진 → 스캔본을 열고 사진을 추가해요. 사진 한 장이 한 쪽이 돼요.
  3. 종이 테두리를 자동으로 찾아 반듯하게 펴줘요. 틀이 어긋나면 모서리 조정을 눌러 네 개의 점을 종이 모서리로 끌어주세요.
  4. 효과를 골라요. 글자 위주면 흑백, 연필 필기는 회색조, 영수증·도장·사진이 있으면 컬러, 펴기만 하려면 원본.
  5. 회전과 화살표로 방향과 순서를 맞춰요.
  6. 모든 쪽을 파일 하나로 받으려면 PDF(A4, 레터, 사진에 맞춤), 따로 받으려면 JPG/PNG를 고르고 저장을 눌러요.

깔끔하게 바뀌는 원리

글자 밑에 깔린 종이의 밝기를 페이지 전체에서 계산한 뒤 고르게 맞춰요. 그래서 손이나 휴대폰 그림자가 사라지고 누런 종이는 하얗게, 글씨는 진하게 남아요.

더 잘 나오게 하려면

  • 빛이 고르게 들어오게 해주세요. 천장 조명 하나보다 낮의 창가가 좋아요.
  • 종이가 사진을 꽉 채우되, 네 모서리는 모두 보이게 찍어주세요.
  • 휴대폰을 흔들리지 않게 잡아주세요. 흔들린 사진은 나중에 고칠 수 없어요.

6. 사진 배경 지우기

배경 지우기는 사람, 반려동물, 상품처럼 사진의 주인공만 남기고 배경을 투명하게 만들어 PNG로 저장해 줘요. 프로필 사진, 쇼핑몰 상품 사진, 스티커, 발표 자료에 쓰기 좋아요.

  1. 배경 지우기를 열고 사진을 한 장 이상 추가해요.
  2. 테두리를 깔끔하게 하려면 고품질, 인터넷이 느리면 빠르게를 골라요. 고품질은 처음 한 번 44MB짜리 인공지능 모델을 받고, 다음부터는 브라우저에 저장된 걸 써요.
  3. 사진마다 처리가 끝날 때까지 기다려요. 원본을 누르면 전후를 비교할 수 있어요.
  4. 배경을 골라요. 투명은 PNG로, 흰색이나 색상은 그 색을 채운 JPG로 저장돼요.
  5. 저장을 누르거나, 여러 장이면 전체 저장을 눌러요.

잘 되는 사진

  • 주인공 하나가 단순한 배경에서 뚜렷하게 보이는 사진
  • 빛이 충분하고 주인공에 초점이 잘 맞은 사진
  • 주인공이 사진 가장자리에서 너무 많이 잘리지 않은 사진

사람이 많은 거리 사진, 날리는 가는 머리카락, 유리처럼 투명한 물건은 자동 도구로는 어려워요. 결과가 깔끔하지 않으면 배경이 단순한 사진으로 다시 해보세요.

7. 잘 안 될 때

  • "이 파일을 그림으로 열 수 없어요"가 뜰 때: 파일이 손상됐거나 확장자가 잘못 붙어 있을 수 있어요. 다른 앱에서 먼저 열어보세요.
  • 저장 버튼을 눌러도 아무 일이 없을 때: 카카오톡 같은 앱 안의 브라우저는 다운로드를 막는 경우가 있어요. 사파리나 크롬으로 열어주세요.
  • 문서 변환 중 오류가 날 때: 암호가 걸린 파일은 읽을 수 없어요. 암호를 푼 뒤 다시 시도해 주세요.
  • 변환이 느릴 때: 아주 큰 문서나 사진은 휴대폰에서 시간이 더 걸려요. 한 번에 올리는 파일 수를 줄여보세요.

8. 자주 묻는 질문

파일이 어딘가에 업로드되나요?

아니요. 페이지가 변환 도구를 브라우저로 불러와서 그 안에서 바로 변환해요. 서버로 보내는 게 없어서, 남에게 보이기 싫은 파일도 안심하고 쓸 수 있어요.

무료인가요?

네. 가입도 필요 없고 파일 개수 제한도 없어요. 운영비를 위해 광고가 보일 수 있어요.

휴대폰에서도 되나요?

네. 최신 사파리, 크롬, 엣지, 삼성 인터넷에서 쓸 수 있어요.
